# history-view

Журнал операций transfer / clipboard. View id: **`history`**.

Строки: тип, размер, скорость, muted expired, превью картинок (без огромных data-URL), кнопки действий через DOM (не `H\`${array}\``). Опрос Neutralino паузится, когда панель скрыта.

## Запуск

```bash
cd modules/views/history-view
npm run dev
npm run build
```
